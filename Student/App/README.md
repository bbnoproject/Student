# 학생 타임라인 프로토타입

`index.html`은 메인 로비 페이지이고, `student.html`은 학생 상세 페이지입니다.
현재 프로토타입에는 `프로젝트 팀 배치/역할 이력`, `반복 협업 팀원`, `취업 문서 진행 이력`, `우수자/위험군 운영 포커스`, `마일스톤별 분석 목적`이 함께 반영됩니다.

실행 순서

1. 데이터 재생성
2. 로컬 서버 실행
3. `http://127.0.0.1:8765/index.html#overview` 열기
4. 학생명 또는 필터를 누르면 `App/student.html?id=학생ID` 또는 학생관리 필터 화면으로 이동

Chart.js는 `App/vendor/chart.umd.min.js` 로컬 파일을 사용합니다. 브라우저 보안 정책과 캐시 문제를 줄이기 위해 정적 파일 직접 열기보다 로컬 서버 확인을 권장합니다.

데이터를 다시 생성하려면 아래 스크립트를 실행합니다.

```powershell
& "C:\Users\안중재\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" .\scripts\build_app_data.py
```

생성 결과물

- `App/data.js`: 실제 `Data` 폴더를 정규화한 프런트엔드 데이터 파일
- `App/index.html`: 메인 로비 페이지
- `App/student.html`: 학생 상세 페이지
- `App/vendor/chart.umd.min.js`: 네트워크 없이 사용하는 Chart.js 로컬 번들
- `App/scripts/common.js`: 공통 유틸, 차트, 태그, 검색 렌더링
- `App/scripts/lobby.js`: 메인 로비 전용 로직
- `App/scripts/student.js`: 학생 상세 전용 로직
- `App/styles.css`: 공통 스타일
- `App/styles/lobby.css`: 메인 로비 전용 스타일
- `App/styles/student.css`: 학생 상세 전용 스타일

현재 출결 표시는 아래처럼 분리됩니다.

- `출결 기록`: 전체 출결 이벤트 수
- `판단 반영 위험`: 성향 판단에 직접 반영되는 `행동/관리형` 출결 수

## 2026-05-22 학생 상세 컨텍스트

학생 상세 페이지는 현재 `과정 운영`, `취업 지도`, `학생 분류`를 동시에 지원하도록 구성되어 있습니다.

주요 탭:

- `현황`: 현재 상태, 검증 자료 기반 개별 강점, 학생군 분류, 취업 지도 요약, 모집 단계 핵심 정보
- `성적`: 5대 역량 지표와 마일스톤별 성장 흐름
- `평가`: 개별 강점, 취업 지도, 운영 평가 근거
- `기록`: 면담 기록 전체, 아침 발표 이력, 마일스톤별 이벤트 상세
- `추가자료`: 모집 정보, 실습 제출, 발표, 학생 작성 원문과 해석, 운영진 학생 정보
- `기본정보`: 학생 기본 프로필

`App/data.js`에는 학생별 `strengthProfile`이 포함됩니다. 이 구조는 학생별 취업 강점을 검증 가능한 자료와 함께 보여주기 위한 데이터입니다.

`strengthProfile` 주요 필드:

- `overview`: 한줄 강점, 신뢰도, 요약
- `motivation`: 게임업계 진입 동기 유형과 근거
- `strengths`: 강점 카드 목록
- `improvements`: 개선점과 코칭 질문
- `behaviorTraits`: 생활 태도와 주변 평가 기반 특징
- `employabilityAngles`: 포트폴리오/면접 활용 관점

강점 카드는 반드시 근거 자료를 포함해야 합니다. 근거는 지원서, 기본정보, 실습 제출, 아침 발표, 학생간 평가, 출결 기록, 면담 기록 등에서 가져오며, 실습 제출물은 파일명과 원본 경로도 함께 표시합니다.

새로 연결된 원본 데이터:

- `Data/아침 발표.md`
- `Data/실습 제출/`
- `Data/모집 결과.xlsx`의 지병, 경제적 어려움, 게임업계 지인 여부, 추천인, 걱정/문의, 화상수업 장비 등 추가 항목

검증된 집계:

- 학생 80명
- 실습 제출 519건
- 아침 발표 97건
- 학생 80명 전원 `strengthProfile` 생성
- 학생 80명 전원 동기 분석 생성

브라우저 확인 예시:

```text
http://127.0.0.1:8765/student.html?id=곽용준&tab=status
http://127.0.0.1:8765/student.html?id=곽용준&tab=evaluation
```

확인해야 할 텍스트:

- `검증 자료 기반 개별 강점`
- `게임업계 진입 동기`
- `취업 활용`
- `개선점과 코칭 질문`

주의:

- `App/data.js`는 파생 산출물이므로 원본 수정은 `Data/`와 `scripts/build_app_data.py`에서 진행합니다.
- 희망 취업 분야에 `게임`이 있다는 이유만으로 기본 배경 강점을 만들지 않습니다.
- 성별과 나이 자체는 강점으로 쓰지 않고, 전공/경력/산출물/거주지 같은 검증 가능한 맥락만 사용합니다.

## 2026-05-21 화면 컨텍스트

### 개요

- 상단은 `전체`, `일반`, `과정이탈` 중심으로 봅니다.
- `지금 볼 운영 포커스`는 현재 단계, 진행 교과, 우수자, 위험군, 최근 1개월 긴급 이슈를 보여줍니다.
- 우수자는 `발전도`, `성실도`, `집중도`로 구분합니다.
- 위험군은 `건강`, `불성실`, `인성`으로 구분합니다.
- 우수자/위험군 분류를 누르면 해당 학생만 필터링된 `학생관리` 화면으로 이동합니다.
- 기본 통계는 Chart.js 기반 차트로 표시합니다.
- 지역 차트는 `수도권`, `강원도`, `충청도`, `전라도`, `경상도`, `제주도`로 구분하며, 조각이나 범례를 누르면 해당 지역 학생관리 필터로 이동합니다.

### 학생관리와 학생 상세

- 학생관리에는 `지역`과 `운영포커스` 필터가 있습니다.
- 운영포커스 필터 상태에서 학생명을 누르면 `student.html?id=학생ID&focus=분류키`로 이동합니다.
- 학생 상세의 `우수자/위험군 평가 근거` 섹션에서 왜 해당 분류로 평가되었는지 확인할 수 있습니다.

### 학습과정

- `#process` 개요는 전체 학생의 모집 단계부터 현재까지 관측된 마일스톤을 기준으로 합니다.
- 출결 기간은 과정 시작일 `2025-12-08`부터 현재 날짜까지입니다.
- 과정 개요 그래프는 Chart.js를 사용하며, 마우스를 올리면 세부 점수가 나옵니다.
- 세부 점수는 `학습 자기조절`, `참여 지속성`, `협업`, `회복탄력성`, `성찰`, `진로 목적성`입니다.
- 하단 `마일스톤별 요약과 핵심 이슈` 카드는 각 단계의 참여 인원, 평균 프로파일, 출석률, 상담 건수, 긴급 이슈를 요약합니다.
- 각 마일스톤 상세에는 `Analysis Purpose` 섹션이 있습니다.
- `Analysis Purpose`는 분석 목적, 수업/자료 범위, 분석 질문, 판단 주의를 보여줍니다.
- 모집 단계는 초기 스펙, 개인정보, 모집 서류, 면접 서술, 지병/건강 제약/경제적 어려움, 자기보고 데이터 신뢰도를 분석합니다.
